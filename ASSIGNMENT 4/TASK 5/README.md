## Objective
To understand how Python programs can be organised using scripts, modules and packages.

## Concepts Used
- Python functions
- Modules
- Packages
- Import statements
- Code reusability
- if __name__ == "__main__"

## Program File
`AT4 T5.py`

## Program Description
The program processes attendance records, calculates student attendance percentages, generates a report and identifies students absent for three consecutive days.

## Four Organisations
1. Single Python script.
2. One module imported by a main script.
3. Three separate modules in one folder.
4. A package containing reader, statistics and report modules.

## Expected Result
- Reads attendance records.
- Calculates attendance percentages.
- Identifies three consecutive absent days.
- Demonstrates modular program organisation.

## Time Complexity
O(n) for the main attendance processing operations, where n is the number of records.

## How to Execute
```bash
python AT4 T5.py
```

## Conclusion
The task demonstrates modular programming, code reuse and different ways of organising Python applications.
