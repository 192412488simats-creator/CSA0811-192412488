
# Task 1 – Daily Rainfall Records

### Objective
To analyse daily rainfall records using Python lists, slicing and moving averages.

### Concepts Used
- List creation and operations
- List slicing
- Maximum and minimum values
- Moving averages
- List processing and timing comparison

### Program File
AT3 T1.py

### Expected Result
The program calculates weekly rainfall totals, identifies wettest and driest weeks, calculates moving averages and counts dry days. It also compares calculation methods for different dataset sizes.

### Execution
Run using:
python AT3 T1.py
